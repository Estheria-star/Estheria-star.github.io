# 心情日历 · Mood Calendar

🐱 **在线使用 → https://startian.top/mood/**

> 用 **43 张猫耳少女表情**记录每天的心情，点一个日子就能写下当天日记（日期 → 天气 → 心情 → 正文）。数据只存在浏览器本地，可离线使用，支持导出备份。

## 功能

- **贴心情**：43 张猫耳表情分「开心 / 低落 / 生气 / 困倦 / 平静 / 五味杂陈」等情绪分区，每天挑一张贴上
- **日记本**：点任意日期展开日记——日期（自动）→ 天气（8 种预设）→ 心情 → 正文自由写；正文自动保存（防抖 500ms）
- **月历回顾**：贴纸 + 天气角标一眼扫过；统计本月记录天数 / 日记篇数 / 最常见心情 / 连续天数
- **深链**：每篇日记有独立地址（`#2026-10-05`），可收藏直达
- **数据自由**：导出 / 导入 JSON 备份（兼容旧版数据自动迁移）

## 技术说明

- 单文件页面 + `stickers/` 43 张 webp 贴纸素材（共约 920 KB）
- 全部逻辑纯前端；数据存 localStorage，不上传
- 支持键盘操作与「回到今天」快捷定位
- 属于「星恬的小站」作品之一
