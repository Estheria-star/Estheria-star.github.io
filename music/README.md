# 函数音乐 · Function Music

🎵 **在线体验 → https://startian.top/music/**

> 把数学函数**画成声波**：不同函数不同音色，图形跟着跳。写一个 `sin(t)` 是纯音，叠几层三角波就是新乐器——零依赖单文件，打开即玩。

## 玩法

- 在输入框写一个周期函数（如 `sin(t) + 0.3*sin(5*t)`），点「应用函数」——它的一个周期波形就成了你的音色
- **试听一小段** / 用电脑键盘或鼠标弹琴键（简谱对照：`1 2 3 4 5 6 7` = do re mi fa sol la si）
- 内置音色预设：纯正弦 / 方波感 / 锯齿 / 三角 / 风琴 / 金属 / 混沌雾 / 阶梯……
- 波形图实时绘制，弹琴时图形跟着跳

## 技术说明

- 单文件、零依赖、纯前端；声音由 **Web Audio API** 合成（波形直接从函数采样而来）
- 函数输入带安全求值与小提示（表达式异常会在界面上提示而不是静默失败）
- 属于「星恬的小站」作品之一
