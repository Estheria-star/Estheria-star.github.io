# 生命游戏花园 · Game of Life

🌱 **在线体验 → https://startian.top/life/**

> 康威生命游戏（Conway's Game of Life）的交互式花园：撒种子看细胞生长，能存「物种」、能让两个物种对撞。零依赖单文件。

## 玩法

- **画细胞**：按住鼠标直接画，选「种植图案」后点网格放置（滑翔机 / 飞船 / 脉冲星 / R-pentomino 等经典图案）
- **拖动平移 / 滚轮缩放 / 右键擦除**
- **存物种**：把当前细胞的排布存成「物种」
- **物种对撞**：让两个物种对撞，看它们擦出什么火花
- 世界稳定后会显示世代数、活细胞数等统计

## 技术说明

- 单文件、零依赖、纯前端；Canvas 渲染（新生青绿 → 老年紫的年龄渐变 + 轻发光）
- 无限网格（可视窗口按需计算），支持大图案
- 属于「星恬的小站」作品之一
