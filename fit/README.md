# 函数拟合器 · Function Fitter

📈 **在线体验 → https://startian.top/fit/**

> 丢一堆散点进去，**自动找出最像的函数**。零依赖单文件、打开即玩。

## 玩法

- **画布撒点**：点击画布加点、右键删除最近的点；也可以直接粘贴数据（每行 `x,y` 或 `x y`）
- 实时拟合：一次 / 二次 / 三次 / 指数 / 幂 / 对数函数同时比拼，**金色边框 = 当前最像的函数**
- 每类函数给出拟合优度评价（几乎完美吻合 / 非常吻合 / 比较吻合……）
- 一键「撒线性点 / 撒抛物线点 / 撒指数点」快速体验

## 技术说明

- 单文件、零依赖、纯前端；最小二乘（含对数域变换）自研实现
- 属于「星恬的小站」作品之一
