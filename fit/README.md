# 函数拟合器 · Function Fitter

📈 **在线体验 → https://startian.top/fit/**

> 丢一堆散点进去，**自动找出最像的函数**。零依赖单文件、打开即玩。

## 玩法

- **画布撒点**：点击画布加点、右键删除最近的点；也可以直接粘贴数据（每行 `x,y` 或 `x y`）
- **11 种模型**同时比拼：一次 / 二次 / 三次 / 四次函数、指数函数、指数函数·偏移、幂函数、对数函数、反比函数、正弦函数、高斯函数 —— **金色边框 = 当前最像的函数**
- 排名按**调整 R²**（更复杂 ≠ 更优；同分时更简单的函数优先），每张卡片同时给出 R² 与调整 R²
- **噪声滑杆**：从 0（完美数据）到 ±3，亲手验证"数据越干净、识别越准"
- 一键体验 7 种数据形态：线性 / 抛物线 / 三次 / 指数 / 正弦 / 钟形 / 反比

## 技术说明

- 单文件、零依赖、纯前端
- 多项式拟合：Householder QR 最小二乘（x 先归一化再展开回原系数，数值稳定）
- 非线性拟合：线性化初值 + Levenberg–Marquardt 精修（数值雅可比），干净数据可精确还原生成参数
- 属于「星恬的小站」作品之一
