万物沙盒EVERYTHING SANDBOX

一块漂浮在星海中的像素土地。选一种元素，在画布上按住拖动，世界就会自己活起来。

一、自由探索（无限世界）

  • 左键拖动 撒下选中的元素
  • 右键拖动 快速擦除
  • 滚轮 缩放（跟随指针）
  • 空格 + 拖动 或 中键拖动 或 双指 平移世界
  • 方向键 / WASD 平移镜头
  • 世界向两侧无限延伸，走到哪生成到哪，没有边界

二、沙盒底下还藏着另一层世界（神秘入口）

  • 左上角那颗小星球，不只是回主页的按钮——按住它别松手，多按一会儿，世界会「翻个面」
  • 翻面之后是另一个世界：W A S D / 方向键 移动、鼠标 转视角（自动锁定，ESC 解锁）
  • 空格 / Shift 升降飞行；不按就贴地行走；滚轮 调整视野
  • 点击画面 在准星处放下方块；选光束笔则沿视线发射光束
  • 想回来：按 V，或先按 ESC 解锁鼠标、再长按那颗星球
  • 那一层里还有别的住客：水面上会「嘎」的鸭子、天上慢慢游过的鲸鱼……自己去看

三、时间倍速

  • 点顶部 ⏩ ×1 循环切换 ×1 → ×2 → ×4 → ×8 → ×16
  • 高倍速下引擎会自动控制步进预算，掉帧时自动保守

四、世界会自己发生的事

  • 水会把火烧成蒸汽，蒸汽飘着飘着又凝成雨落回来
  • 木、油、藤蔓都怕火；火药碰到火会炸；烟花会窜上天炸开
  • 种子落在水边会发芽，落在泥土/沙地上也会慢慢发芽长藤
  • 酸能吃穿石头却怕玻璃；岩浆又烫又亮，遇到水会凝固成石头

五、光会拐弯（炫技点）

  • 选 ✨ 光束笔，按下并拖动来瞄准，松手前光束会一直跟着手指走
  • 光束会被 镜 / 镜 \ 反射、被玻璃折射、进棱镜散成彩虹
  • 光能点燃路上的油和木头；拿镜子铺一条光路试试

六、物理与天空

  • 用 ⚪ 钢球 点一下生成滚球：会滚坡、扬尘、犁沙、球撞球
  • 用 🪢 绳 钩住一点，垂下来的绳子会自己荡（也会被烧断）
  • 选 🌀 星流 在天空划动，能把极光搅出漩涡，还能吹散烟
  • 天空里偶尔有流星；星域来客偶尔路过，也会偶尔帮你烧点什么

七、隐藏起来的小事

  • 试试老派游戏秘技（↑↑↓↓←→←→ B A）
  • 左上角那颗星球按得够久，据说会翻出世界的另一面……（先别急着松手）
  • 走远一点，也许会有成就悄悄亮起来
  • 更多等你慢慢撞见
