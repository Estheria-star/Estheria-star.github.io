# 万物沙盒 · Everything Sandbox

🏖 **在线游玩 → https://startian.top/sandbox/**

> 一块漂浮在星海中的像素大陆：22 种元素互相反应、光束反射与棱镜色散、流体极光、钢球滚过山丘，还能「潜入」隐藏的真·第一人称 3D 世界。单文件约 190 KB、零依赖、打开即玩。

## 玩法

- 选一种元素，在画布上按住拖动，世界就会自己活起来
- **左键拖动**撒元素 · **右键拖动**擦除 · **滚轮 / 双指捏合**缩放（跟随指针）· **空格+拖动 / 中键 / 双指**平移 · **双击**复位视图
- 笔刷大小可调，最左 = 单格（1 像素）
- 底部工具栏切换元素、倍速（×1 ~ ×16）、清空、新世界、光之相机（导出 PNG）、召唤星域来客
- **左上角那颗小星球，不只是回主页按钮**——按住它别松手，多按一会儿，世界会「翻个面」

## 五大系统

1. **物质沙盘**：22 种元素互相反应——水把火烧成蒸汽、蒸汽凝成雨落回来；火药碰到火会炸；种子落在水边会发芽长藤；酸能吃穿石头却怕玻璃
2. **流体极光**：鼠标划过天空能搅出漩涡、吹散烟雾
3. **无限星空**：分块哈希生成的 3 层视差星空，往两侧无限延伸，偶有流星
4. **2D 光之追踪**：光束反射（镜面）/ 折射（玻璃）/ 棱镜散成彩虹，逐帧生长，还能点燃路上的油和木头
5. **物理与天穹**：钢球刚体（滚坡、扬尘、球撞球）、verlet 绳、星域来客舰队不时路过

## 隐藏的真·第一人称 3D 世界

- 长按左上角星球「翻面」进入：体素高度场逐列射线行军渲染 + 深度错切 + 距离雾
- **WASD / 方向键**移动（贴地走，空格 / Shift 升降飞行）、**鼠标**转动视角（自动锁定，ESC 解锁）
- **点击画面**在准星处放置方块；选光束笔则沿视线发射光束
- 渲染分辨率自适应（55% ~ 100%，EMA 调档），拖动流畅不糊

## 技术说明

- **纯前端单文件**（约 190 KB）：Canvas 2D 手写渲染管线，无任何第三方库
- 无限世界：`TILE=128` 分块 + 512 格活动窗口，自由平移缩放探索
- 事件总线解耦（`world:blast` / `mode:3d-enter` 等），模块地图见工程内 `ARCHITECTURE.md`
- 列缓存（TTL 1.2s）+ 防震荡自适应，性能约 0.25ms/步（320×180 网格）
- 成就 **48 枚**，与小站跨站成就柜互通
- 本目录为构建产物；源码为 `src/` 分片 + `build.py`
