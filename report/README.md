# 今日份诊断报告 · Daily Diagnosis

🩺 **在线体验 → https://startian.top/report/**

> 每次刷新生成一张「今日份体检单」：精神状态 / 专注力 / 欧气 / 发量 / 战斗力 / 睡意 / 玄学值……**同一天永远同一份**，还能保存成图分享。仅供开心，不作任何医疗建议。

## 玩法

- 打开就是今天的报告：各项指标 + 综合分 + 评级 + 一句「体检结论」
- 不满意可以「换一份（今日变体）」——同一天内切换不同版本
- **保存报告图** / **分享链接**，拉朋友来做个「体检」
- 每天打开都一样（按日期播种），明天又是新的你

## 技术说明

- 单文件、零依赖、纯前端；报告由**日期做种子的伪随机算法**生成（同一天恒定）
- Canvas 绘制报告图，无任何后端
- 属于「星恬的小站」作品之一
