# 六边形维度展示器 · 无上限

⬡ **在线把玩 → https://tujie.startian.top/**

> 无限展开的六边形几何展示器：多层级嵌套、旋转与配色实验，随手转一转就挺上头，适合发呆时玩的小玩具。零依赖单文件、打开即玩。

## 玩法

- 点击 / 拖动操作，六边形多层级**无限嵌套**展开
- 层级、尺寸、旋转、配色可调，配色随手换一套就是新感觉
- 支持**播放动画 / 录制 / 停止**，把喜欢的转法录下来

## 技术说明

- 单文件、零依赖、纯前端；Canvas 绘制
- 属于「星恬的小站」作品之一
