# 宇宙地图 · Universe Map

🗺 **在线体验 → https://startian.top/map/**

> 星恬小站的全站导航：每一件作品是一颗星，在宇宙里自由漂浮、彼此靠近时自动连线；**去过的会亮起来**，点击星星可展开「星图关系视图」。

## 玩法

- 星星在宇宙中**持续自由运动**（实时演算），鼠标悬停会「冻结」那颗星方便细看
- 星星靠近时**自动连线**，看得出作品之间「同属一个银河系」
- **去过就亮**：凭浏览记录（cookie 足迹）点亮你访问过的作品星
- 点星星：展开卡片；`Ctrl / 中键` 直接出发去那个作品
- 侧栏可切换「星图关系视图」看全部关系

## 技术说明

- 单文件、零依赖、纯前端；Canvas 实时演算（rAF）
- 与全站成就系统联动：足迹、连线、点亮都与 cookie（`.startian.top`）共享
- 属于「星恬的小站」作品之一
