# 配色实验室 · Color Lab

🎨 **在线体验 → https://startian.top/colorlab/**

> 选两个颜色，实时预览一整套 UI，一键导出 CSS 变量。零依赖单文件、打开即玩。

## 玩法

- 挑一个**底色** + 一个**主色**，右边的示例界面（卡片 / 按钮 / 输入框 / 图表）瞬间跟着变
- 内置配色预设，也可以随手调出自己喜欢的组合
- 一键**导出 CSS 变量**（`:root { --color-bg: … }`），直接拿去用在自己的页面里

## 技术说明

- 单文件、零依赖、纯前端；全套派生色（文字 / 边框 / 悬浮态）由两色自动生成
- 属于「星恬的小站」作品之一
