# 错题本 · Mistake Notebook

📕 **在线使用 → https://startian.top/cuoti/**

> 错题本 + 间隔重复复习：把错题记下来，按记忆曲线**自动安排复习时间**——让时间帮你记住。零依赖单文件，数据只存浏览器本地。

## 功能

- **录入错题**：题干 / 正确答案 / 当时错因 / 科目 / 标签 / 难度（基础 / 中等 / 压轴）
- **间隔重复**：每道题按你的掌握程度安排下次复习（忘了 / 模糊 / 记得 / 简单 四档评分，动态调整记忆系数）
- **今日复习**：一键开始复习，翻面看答案、键盘 `1/2/3/4` 快速评分
- **统计**：掌握进度、连续复习天数、最近 7 天复习量、科目分布
- **数据自由**：导出 / 导入 JSON 备份
- 内置示例题，体验完可一键删掉

## 技术说明

- 单文件、零依赖、纯前端；间隔重复算法（简化 SM-2：记忆系数 + 间隔演进）自研
- 数据存 localStorage，不上传、不登录
- 属于「星恬的小站」作品之一
