# 无限星空生成器 · Infinite Starfield

✨ **在线体验 → https://startian.top/star/**

> 输入种子编号生成一片独一无二的星空，**往任何方向拖动都无限延伸**；可缩放探索、下载做壁纸，种子 + 视角可分享。零依赖单文件。

## 玩法

- 输入任意**种子号**（如 `1818`）生成一片只属于这个种子的星空；点种子号可随时修改
- 拖动 / 滚轮自由探索——世界向任何方向**无限延伸**，走到哪生成到哪
- 右键缩放 UI 里的 ⌖ 回到原点；「分享这颗」把**种子 + 当前视角**打包成链接
- 下载当前画面做壁纸

## 生成美学

- 分块哈希（chunk）程序化生成：同一种子永远同一片星，不存图不占内存
- 多层视差 + 星星分级：远星微亮、近星带光晕、稀有行星藏在深处
- 调色板随时间轴演变，同一种子也能翻出不同风格的星空

## 技术说明

- 单文件、零依赖、纯前端；Canvas 渲染
- 无限世界实现：`TILE` 分块 + 确定性哈希，几何级压缩的「无限」
- 属于「星恬的小站」作品之一
